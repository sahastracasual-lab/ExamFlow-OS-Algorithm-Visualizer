CPU Scheduling — FCFS

First-Come, First-Served. Enter one process per line as Process, Arrival Time, Burst Time. Example: P1,0,5

Run the calculation to see the schedule.

Process Synchronization — Producer–Consumer

A producer places submitted-answer jobs into a bounded queue; an evaluator consumes them. This is a step-by-step logical simulation of buffer synchronization.

Deadlock Avoidance — Banker’s Algorithm

Use the preset examination-processing example or edit the matrices. Need = Maximum − Allocation. Values are illustrative units of three resource types (A, B, C).

Run the safety check to calculate Need and search for a safe sequence.

Memory Management — First Fit / Best Fit

Compare two placement strategies. Enter free block sizes and process sizes as comma-separated numbers, then choose First Fit or Best Fit.

Run allocation to view placements and remaining free memory.
